# Adaptive Network Design and Optimization Framework (Assignment 4)
Course: Design and Analysis of Algorithms (AI ML Leopards) | Faculty: Prof. Geeta Tripathi[cite: 1]

## Overview
This repository implements an adaptive network optimization framework applied to a **Smart-Port & Autonomous Logistics Grid**. The system dynamically integrates graph optimization, dynamic data structures, resource budgeting, and combinatorial search to manage changing network conditions[cite: 7].

## Prescribed DAA Components Implemented
1. **Minimum-Cost Backbone:** Prim's vs. Kruskal's algorithms evaluated across sparse and dense graph topologies[cite: 7].
2. **All-Pairs Cost Analysis:** Floyd-Warshall algorithm for network-wide transit planning[cite: 7].
3. **Network State Data Management:** B-Tree (disk-bound logs) vs. Red-Black Tree (active routing)[cite: 7].
4. **Event Prioritization:** Binomial Heap vs. Fibonacci Heap performance trade-offs[cite: 7].
5. **Upgrade Budgeting:** Fractional Knapsack (divisible upgrades) vs. 0/1 Knapsack (indivisible upgrades)[cite: 7].
6. **Maintenance Tour & Complexity:** TSP solved via exact Backtracking, accompanied by an explicit NP-Hard scalability discussion[cite: 7].
